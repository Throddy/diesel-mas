# Словарь данных

## Канонический объект Observation

| Поле | Смысл |
|---|---|
| `timestamp` | время измерения, единственный ключ синхронизации |
| `process_unit` | АВТ / Гидроочистка |
| `sample_point` | точка отбора, значения 1, 2, 2.1, 3, PAK |
| `canonical_metric` | канонический показатель после alias registry |
| `raw_metric` | исходное имя показателя |
| `value`, `original_unit`, `canonical_unit` | значение и единицы до конверсии и после неё |
| `source` | TELEMETRY / LIMS / PAK / VAK |
| `data_quality_flags` | `NONNUMERIC_VALUE`, `DUPLICATE_TIMESTAMP`, `UNIT_ASSUMPTION:A-03` и другие |
| `analyzer_health` | OK / SUSPECT / FAILED / MISSING |
| `age_at_decision_min` | возраст значения на момент решения |

## Моменты времени

| Поле | Смысл |
|---|---|
| `t_sample` | время отбора пробы или измерения, в канонических рядах это индекс |
| `t_result_available` | время получения результата, для ЛИМС равно `t_sample` плюс 120 мин |
| `t_decision` | момент сбора признаков и принятия решения |
| `target_time` | `t_decision` плюс горизонт прогноза |

Признак, анализ или остаток калибровки допускается к использованию только при
`t_result_available` не позже `t_decision`. `Dataset.meta` хранит
`decision_time`, `sample_time` и `result_available_time` для каждой строки.
| `original_reference` | файл и колонка-источник |

## Целевой показатель

`Гидроочистка | точка 2 | Mg.Sulfur`, мг/кг, сера в гидроочищенном ДТ.
1462 значения, с 2023-01-01 по 2026-08-09, медиана 8,6, максимум 2120, 230 значений выше 10.

## Прокси-показатели

- Производительность: `ht:F17`, расход гидроочищенного ДТ в цех №8 (это результат, не управление).
- Энергия/стоимость: `0.5*avt:F29/med + 1.0*avt:T55/med + 1.0*ht:T5/med + 0.5*ht:F15/med`, безразмерный, экономических данных в пакете нет.
- Надёжность: робастные z-отклонения 9 сигналов от медианы train, включая `ht:W10` (перепад давления Р-202).
