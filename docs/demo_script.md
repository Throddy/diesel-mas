# Порядок демонстрации

Показ рассчитан на 5 мин. Числа берутся с экрана или из
[reports/results_summary.md](../reports/results_summary.md), поскольку
изменяются с каждым прогоном.

## Задача, 0:00 по 0:30

Цепочка АВТ, гидроочистка 24-2000, блендинг. Жёсткое ограничение одно.
Содержание серы в продукте гидроочистки не выше 10 мг/кг. Соответствие
товарной смеси не подтверждается, поскольку данных о компонентах смешения
нет.

Цикл решения включает проверку данных, прогноз с интервалом, оценку тяжести
режима, генерацию вариантов воздействия, отсев по жёстким ограничениям и
карточку оператора либо обоснованный отказ.

## Данные, 0:30 по 1:00

Показать [reports/data_audit.json](../reports/data_audit.json) с объёмом
телеметрии, лабораторных рядов, покрытием поточного анализатора и найденными
флэтлайнами. Открыть
[reports/excluded_periods.csv](../reports/excluded_periods.csv), где каждая
строка содержит начало, конец, причину и детектор.

## Стабильный режим, 1:00 по 1:50

```bash
python -m scripts.demo --scenario stable
```

Запас до предела достаточен, система удерживает режим. Обратить внимание на
величину запаса, который позволяет не менять управление.

## Риск по качеству, 1:50 по 2:50

```bash
python -m scripts.demo --scenario quality-risk
```

Верхняя граница прогноза выше предела. Система предлагает изменение
температуры и расхода сырья с указанием величины, темпа и ожидаемого эффекта.
Показать блок риска с вероятностью превышения и ценой вариантов.

## Недостоверные данные, 2:50 по 3:50

```bash
python -m scripts.demo --scenario bad-data
```

Отказ анализатора и устаревший лабораторный анализ. Система отказывается и
называет причину.

## Дашборд, 3:50 по 4:30

```bash
streamlit run app.py
```

Девять вкладок. Показать карточку оператора, вкладку горизонтов с прогнозом,
интервалом, вероятностью превышения и возрастом последнего анализа,
трассировку агентов с выходом каждого агента и журнал обмена сообщениями с
раундами перепланирования.

## Ограничения, 4:30 по 5:00

Открыть [Ограничения применения](../README.md#ограничения-применения).
Блок оценки участвовал в выборе конфигурации, покрытие интервала ниже
номинального, предел проверяется для продукта гидроочистки, причинный эффект
управляемых параметров не установлен. Оценка альтернатив приведена в разделе
[Экспериментальная оценка альтернатив](../README.md#экспериментальная-оценка-альтернатив).
