# Комплект сдачи

Репозиторий содержит код, конфигурацию, документы, отчёты и исходные данные
организаторов. После клонирования решение запускается без дополнительных
загрузок.

## Состав комплекта

| Часть | Расположение | Размер |
|---|---|---|
| Код, конфигурация, документы, отчёты | репозиторий | около 2 МБ |
| Исходные файлы организаторов | `data/raw/` | 105 МБ |
| Промежуточный и обученный слой | `data/interim/`, `models/` | генерируются, в git не входят |

Свежий клон занимает около 219 МБ. Рабочая копия весит 105 МБ, столько же
занимает история git, поскольку архив телеметрии хранится обычным файлом без
Git LFS.

предлагает Git LFS. На работу решения это не влияет.

## Порядок воспроизведения

Требуется Python 3.11 или новее.

```bash
git clone https://github.com/Throddy/diesel-mas.git && cd diesel-mas
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # в закрытой сети: --no-index --find-links=wheelhouse
python run_all.py
streamlit run app.py
```

Полный прогон занимает около 13 мин. Он включает подготовку данных, обучение,
оценку, тесты, эксперименты, демонстрационные сценарии, расчёт документируемых
периодов и рендер публикуемых чисел.

Файлы организаторов уже лежат в `data/raw/`. Другой каталог задаётся флагом
`--data-dir`. Интернет не требуется ни на одном шаге, что проверяется тестом с
отключёнными сокетами.

Периоды, значения которых приведены в документации, перечислены в
`reporting.periods` конфигурации и считаются при каждом прогоне. Расчёт за
произвольный период добавляется флагами.

```bash
python run_all.py --start 2026-01-01 --end 2026-02-01
python -m scripts.backtest --start 2026-03-01 --end 2026-04-01 --cycles 24
```

Результат сохраняется в `reports/periods/<начало>_<конец>/backtest.json`.

## Исключённые периоды

Из обучения, модельных диапазонов и оценки тяжести режима исключены 92
интервала. Каждая строка `reports/excluded_periods.csv` содержит начало,
конец, причину и детектор.

| Причина | Интервалов |
|---|---|
| TRANSIENT | 40 |
| SHUTDOWN | 23 |
| PAK_FLATLINE | 18 |
| SENSOR_FAULT:ht:P3 | 8 |
| LIMS_IMPLAUSIBLE | 3 |

Исключение действует на обучение и на выдачу рекомендаций. В аудите данных
эти периоды остаются видимыми.

## Проверка целостности

`manifest.json` содержит коммит кода, версии пакетов и SHA-256 каждого
исходного файла. Свежий манифест создаётся командой `python -m src.manifest`.
